# 🧱 BlockCraft
### Build worlds. Break limits. Make it yours — by permission.

**BlockCraft** is an independent voxel sandbox project with a big ambition: to build a living, explorable block-based world from the ground up. We’re working toward the creativity, survival systems, and endless discovery that make this genre special — powered by our own implementation and original assets.

> 🚧 **Early development:** BlockCraft is at the foundation stage. The roadmap describes the vision, not a claim that every listed feature is already implemented.

## 🌍 The vision
- **A world made of blocks** — procedural terrain, caves, trees, water, and places worth exploring.
- **Build without limits** — break and place blocks, shape landscapes, and create your own structures.
- **Survival and progression** — inventory, crafting, tools, health, creatures, and a day/night cycle.
- **A world that remembers** — save and load your worlds locally.
- **Designed to grow** — a modular block registry and data-driven content for future expansion.
- **Windows first** — a polished desktop experience, with a launcher for settings, diagnostics, updates, and logs.
- **Multiplayer later** — the first milestone focuses on making single-player stable and fun.

## 🛠️ Development roadmap
1. [ ] Reliable Java build and Windows CI
2. [ ] 3D rendering, player camera, and movement
3. [ ] Chunk-based terrain and original textures
4. [ ] Mining, block placement, and collision
5. [ ] Inventory, crafting, and world save/load
6. [ ] Lighting, fluids, entities, and deeper sandbox systems
7. [ ] Launcher, diagnostics, update flow, and installer
8. [ ] Multiplayer architecture and networking

Milestones may change as development and testing reveal what should come next.

## 🧪 Build status
The repository uses **Java + Gradle** and is being prepared for automated Windows builds with **GitHub Actions**. A successful build or downloadable release will only be announced after the workflow has actually completed and its artifacts have been checked.
